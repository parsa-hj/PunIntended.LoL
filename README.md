# PunIntended.lol

A modern, interactive web application that generates witty puns with style. Built with pure HTML, CSS, and JavaScript.

## Features

### Core Functionality
- **Smart Pun Generation**: 25+ carefully curated puns across 5 themed categories
- **No Repetition Algorithm**: Ensures users don't see the same pun twice until all are exhausted
- **Category System**: Dad Jokes, Food Puns, Animal Puns, Tech Puns, and Science Puns
- **Keyboard Shortcuts**: Press spacebar to generate new puns quickly

### User Experience
- **Interactive Animations**: 3D rotation effects and smooth transitions
- **Reaction System**: 5 emoji reactions with floating animation feedback
- **Live Statistics**: Tracks puns generated, reactions given, and "cringe level"
- **Social Sharing**: Copy to clipboard or native share API support
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices

### Easter Eggs
- **Konami Code**: Secret rainbow animation (↑↑↓↓←→←→BA)
- **Hidden Shortcuts**: Spacebar for quick pun generation
- **Dynamic Stats**: Gamified experience with growing statistics

## Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs entirely client-side

### Installation
1. Download the HTML file
2. Open in any web browser
3. Start generating puns immediately!

## Technical Details

### Built With
- **HTML5**: Semantic markup and modern standards
- **CSS3**: Advanced animations, gradients, and glassmorphism effects
- **Vanilla JavaScript**: No frameworks or dependencies
- **Google Fonts**: Fredoka One and Open Sans typography

## Usage

### Basic Usage
1. Visit the website
2. Click "Generate Epic Pun!" button
3. Enjoy the pun and react with emojis
4. Share your favorite puns

### Categories
- **Dad Jokes**: Classic groan-worthy humor
- **Food Puns**: Culinary comedy gold
- **Animal Puns**: Creature-feature comedy
- **Tech Puns**: Programming and technology humor
- **Science Puns**: STEM-themed wordplay

## Analytics & Tracking

The app includes built-in engagement tracking:
- **Puns Generated**: Total number of puns viewed
- **Groans Created**: Total emoji reactions given
- **Cringe Level**: Calculated engagement score

*Note: All data is stored locally in memory and resets on page refresh*
